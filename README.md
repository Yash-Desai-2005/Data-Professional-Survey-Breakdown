# 📊 Data Professional Survey Breakdown

## 📌 Project Overview

This project analyzes survey responses from **630 data professionals** using Microsoft Power BI. The dashboard provides insights into job roles, salaries, programming language preferences, job satisfaction, work-life balance, and the challenges of entering the data industry.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query Editor** – Data cleaning and transformation
- **Microsoft Excel** – Source data

## 🧹 Data Cleaning & Transformation

The dataset was prepared using Power Query Editor. The main steps included:

- Removing unnecessary columns
- Splitting columns by delimiters
- Replacing values where required
- Changing data types
- Creating and transforming columns for analysis

## 📈 Dashboard Features

The dashboard includes the following visualizations and metrics:

- **Country of Survey Takers:** Distribution of respondents by country
- **Average Salary by Job Title:** Comparison of salaries across data-related roles
- **Favorite Programming Language:** Analysis of programming language preferences
- **Difficulty to Break Into Data:** Respondents' views on entering the data industry
- **Happiness with Work-Life Balance:** Average work-life balance rating
- **Happiness with Salary:** Average salary satisfaction rating
- **Key Metrics:** Total survey respondents and average age

## 🔍 Key Metrics

- **Total Respondents:** 630
- **Average Age:** 29.87 years
- **Average Work-Life Balance Rating:** 5.74
- **Average Salary Satisfaction Rating:** 4.27

*Note: Ratings are displayed as shown in the Power BI dashboard.*

## 🚀 How to Run This Project

1. Download the Power BI report (`.pbix`) and its Excel source file from this repository.
2. Install and open Microsoft Power BI Desktop.
3. Open the `.pbix` file.
4. If Power BI cannot locate the Excel source, update the data source path to the downloaded Excel file.
5. Refresh the data if required and explore the dashboard.
